### 📌 ข้อมูลทั่วไปของระบบ (General Information)
- **ชื่อระบบ:** DBASE Learning AI (ระบบเรียนรู้วิชาโปรแกรมฐานข้อมูลอัจฉริยะ)
- **วัตถุประสงค์การวิจัย:** เพื่อพัฒนาและหาประสิทธิภาพของระบบจัดการเรียนรู้อัจฉริยะร่วมกับผู้ช่วยสอนปัญญาประดิษฐ์ (AI Assistant) ในรายวิชาโปรแกรมฐานข้อมูล ตามเกณฑ์มาตรฐานนวัตกรรมทางการศึกษา
- **หน่วยงานพัฒนา:** แผนกวิชาคอมพิวเตอร์ธุรกิจ / เทคโนโลยีธุรกิจดิจิทัล วิทยาลัยอาชีวศึกษาสุราษฎร์ธานี
- **ผู้วิจัยและพัฒนา:** ครูปาณวัฐ รักรอดจิต และคณะ
- **ลิงก์เข้าใช้งานระบบจริง (Production URL):** [https://dbase-learning.vercel.app](https://dbase-learning.vercel.app)
- **เทคโนโลยีหลัก:** Next.js 16 (App Router), React 19, TypeScript, Supabase (PostgreSQL, Realtime, Storage, Auth), Google Gemini AI API (`@google/genai`), Tailwind CSS, Lucide Icons

## 1. คำชี้แจงสำหรับผู้เชี่ยวชาญในการประเมินระบบ

เรียน ท่านผู้เชี่ยวชาญที่เคารพ

ระบบ **DBASE Learning AI** ได้รับการออกแบบขึ้นเพื่อเป็นนวัตกรรมการเรียนรู้ดิจิทัล โดยผสานพลังของ **Generative AI (Google Gemini)** และระบบบริหารจัดการการเรียนรู้สมัยใหม่ (Modern LMS) เพื่อแก้ปัญหาการเรียนรู้วิชาโปรแกรมฐานข้อมูล ซึ่งเป็นวิชาที่ต้องอาศัยทั้งความเข้าใจเชิงนามธรรม (แนวคิดฐานข้อมูล, Normalization, ER-Diagram) และทักษะเชิงปฏิบัติ (การเขียนคำสั่ง SQL, การสร้างและจัดการตารางข้อมูล)

เพื่อความสะดวกในการประเมิน ขอความอนุเคราะห์ท่านผู้เชี่ยวชาญดำเนินการทดสอบตามลำดับขั้นตอน (Evaluation Flow) ดังนี้:

```
[1. ทดสอบฝั่ง Admin/ครู] ──▶ จัดการเนื้อหา ──▶ ทดลอง AI ออกข้อสอบ ──▶ ตรวจงาน ──▶ ดูสถิติทุจริต/ประเมินผล
         │
         ▼
[2. ทดสอบฝั่ง นักเรียน]  ──▶ ศึกษาบทเรียน ──▶ สนทนากับ AI Tutor ──▶ ทำข้อสอบ (ลองสลับแท็บ) ──▶ รับเกียรติบัตร
         │
         ▼
[3. ประเมินคุณภาพ]     ──▶ บันทึกคะแนนในแบบประเมินผู้เชี่ยวชาญ (ท้ายเอกสารนี้)
```

## 3. คู่มือการใช้งานระบบ: ส่วนของครูผู้สอนและผู้ดูแลระบบ (Admin / Teacher Portal)

### 3.1 การเข้าสู่ระบบและการรักษาความปลอดภัย
1. ไปที่ลิงก์ `/admin/login`
2. กรอก **Username** และ **Password** ที่ได้รับมอบหมาย
3. กดปุ่ม **"เข้าสู่ระบบหลังบ้าน"**
4. **ฟีเจอร์ความปลอดภัย:**
   - ระบบใช้ **HTTP-Only Cookies** เข้ารหัสแบบ **HMAC Cryptographic Signing** ป้องกันการดักจับข้อมูลเซสชัน
   - มีระบบ **Auto-Logout (Idle Timeout 60 นาที)** หากไม่มีการเคลื่อนไหว เพื่อป้องกันความปลอดภัยในกรณีลืมลงชื่อออกจากเครื่องส่วนกลาง

---

### 3.2 แดชบอร์ดภาพรวมระบบ (Analytics Dashboard - `/admin`)
หน้าแรกหลังเข้าสู่ระบบ จะสรุปสถิติสำคัญของการจัดการเรียนการสอนแบบ Real-time:
- **การ์ดสถิติภาพรวม (KPI Cards):** แสดงจำนวนนักเรียนทั้งหมด, จำนวนรายวิชา, งานที่รอตรวจ (Pending Grading) พร้อม Badge สีแดงเตือน, และจำนวนข้อความที่ยังไม่ได้เปิดอ่าน
- **ระบบแจ้งเตือนภาระงานด่วน:** แจ้งให้ครูทราบทันทีเมื่อมีใบงานที่นักเรียนส่งเข้ามาใหม่ หรือมีนักเรียนส่งข้อความขอคำปรึกษา
- **อัตราความสำเร็จและการมีส่วนร่วม:** แสดงร้อยละของนักเรียนที่ผ่านเกณฑ์ และนักเรียนที่ต้องการความช่วยเหลือเป็นพิเศษ (At-risk Students)

### 3.3 การจัดการหลักสูตรและบทเรียน (Course & Curriculum Management - `/admin/courses`)
ช่วยให้ครูผู้สอนสามารถออกแบบโครงสร้างหน่วยการเรียนรู้ได้อย่างยืดหยุ่น:
1. **การสร้างรายวิชา:** คลิก **"เพิ่มรายวิชาใหม่"** กรอกชื่อวิชา, รหัสวิชา (21910-2012), รายละเอียด และอัปโหลดภาพหน้าปก
2. **การจัดการหน่วยการเรียน (Modules):** สามารถเพิ่มหน่วยการเรียนรู้ เช่น หน่วยที่ 1 ความรู้เบื้องต้นเกี่ยวกับฐานข้อมูล, หน่วยที่ 2 ภาษานิยามข้อมูล (DDL), หน่วยที่ 3 ภาษาจัดการข้อมูล (DML)
3. **ระบบจัดลำดับด้วยการลากวาง (Drag & Drop):** ใช้เมาส์ลากจัดลำดับสลับบทเรียนและหน่วยการเรียนรู้ได้อย่างอิสระ
4. **ตัวแก้ไขเนื้อหาบทเรียน (Rich Text Editor):**
   - รองรับการฝังวิดีโอจาก YouTube หรือ Direct MP4 Player
   - รองรับการแนบลิงก์เอกสารประกอบการสอน และไฟล์ PDF
   - แถบเครื่องมือจัดรูปแบบข้อความ โค้ด ตาราง และรูปภาพ

### 3.4 ระบบสร้างข้อสอบอัตโนมัติด้วย AI (AI Quiz Generator)
จุดเด่นสำคัญของระบบที่นำเทคโนโลยี Google Gemini AI มาช่วยแบ่งเบาภาระครูผู้สอน:
1. เข้าไปที่บทเรียนประเภท **"แบบทดสอบ (Quiz / Test)"**
2. คลิกปุ่ม **"สร้างข้อสอบด้วย AI (AI Quiz Generator)"**
3. กำหนดค่าที่ต้องการ:
   - **หัวข้อที่ต้องการออกข้อสอบ (Topic):** เช่น "คำสั่ง SQL SELECT, WHERE, ORDER BY" หรือ "การทำ Normalization ระดับ 1NF ถึง 3NF"
   - **จำนวนข้อที่ต้องการ:** เช่น 5, 10, หรือ 20 ข้อ
   - **ระดับความยาก (Difficulty):** ง่าย (Easy), ปานกลาง (Medium), ท้าทาย (Hard)
4. กดปุ่ม **"ให้ AI ออกข้อสอบ"**
5. ระบบจะส่ง Prompt ที่ออกแบบเฉพาะ (Prompt Engineering) ไปยัง Gemini AI เพื่อประมวลผลและสร้าง:
   - ข้อคำถามที่ตรงตามตัวชี้วัด
   - ตัวเลือก 4 ตัวเลือก (ก, ข, ค, ง)
   - ระบุตำแหน่งเฉลยที่ถูกต้อง
   - คำอธิบายเหตุผลอย่างละเอียดของข้อถูกและข้อผิด
6. ครูผู้สอนสามารถตรวจสอบ แก้ไข หรือกด **"นำเข้าข้อสอบลงสู่บทเรียน"** ได้ในคลิกเดียว
7. **ฟังก์ชัน Smart Paste:** หากมีข้อสอบเดิมอยู่ใน Word/Text สามารถคัดลอกมาวางในช่อง Smart Paste เพื่อให้ระบบแยกข้อ, ตัวเลือก และเฉลยเข้าสู่ฐานข้อมูลอัตโนมัติ

### 3.5 ศูนย์ตรวจงานและประเมินผลตามเกณฑ์รูบริก (Grading Center - `/admin/grading`)
1. เข้าเมนู **"ตรวจงานและข้อสอบ"**
2. ระบบจะแยกแท็บ:
   - **งานที่รอตรวจ (Pending):** แสดงรายการส่งงานใหม่ของนักเรียน
   - **งานที่ตรวจแล้ว (Graded):** ประวัติการให้คะแนนย้อนหลัง
3. ตัวกรองข้อมูล (Filters): กรองตามรายวิชา, ตามหน่วยการเรียนรู้, หรือค้นหาชื่อนักเรียน
4. **การตรวจงาน:**
   - คลิกเลือกรายการของนักเรียน
   - ระบบจะแสดงไฟล์ที่นักเรียนอัปโหลด (รองรับ .accdb, .sql, .docx, .pdf, .zip) พร้อมปุ่มดาวน์โหลด/เปิดดูไฟล์
   - ตรวจสอบคำตอบข้อเขียน (Essay Answers)
   - กรอกคะแนนที่ได้ โดยระบบแสดงคะแนนเต็มและเกณฑ์รูบริกกำกับ
   - พิมพ์ **"คำแนะนำและข้อเสนอแนะจากคุณครู"** เพื่อส่งเสริมการเรียนรู้เชิงสร้างสรรค์
   - กด **"บันทึกผลการตรวจ"** ระบบจะส่งคะแนนและข้อความแจ้งเตือนกลับไปยังหน้าจอนักเรียนทันที

### 3.6 การจัดการข้อมูลนักเรียนและส่งออกคะแนน (Student Management - `/admin/students`)
1. เข้าเมนู **"จัดการนักเรียน"**
2. **ระบบบัญชีรายชื่อ:** แสดงรหัสนักศึกษา, ชื่อ-สกุล, เลขที่, ชั้นเรียน/ห้อง, อีเมล, และความก้าวหน้าการเรียน
3. **การค้นหาและจัดเรียง:**
   - กรองตามห้องเรียน
   - คัดกรองตามสถานะความก้าวหน้า
   - จัดเรียงตามเลขที่ (Sequence Number), รหัสนักเรียน หรือชื่อ-สกุล ก-ฮ
4. **เมนูการจัดการรายบุคคล (Action Menu):**
   - ดูสถิติและคะแนนสอบรายบุคคล
   - แก้ไขข้อมูลส่วนตัว / หมายเลขเลขที่
   - รีเซ็ตรหัสผ่าน หรือรีเซ็ตความก้าวหน้าในกรณีที่ต้องการให้ทดสอบใหม่
5. **การส่งออกรายงานคะแนน (Export Excel Report):**
   - คลิกปุ่ม **"ส่งออก Excel"**
   - ระบบจะสร้างไฟล์ Spreadsheet คุณภาพสูง มีการจัดหัวตาราง (Header Banner), สรุป KPI การ์ด, คะแนน Pre-test / Post-test และคะแนนเก็บทุกหน่วยการเรียน พร้อมสูตรคำนวณค่าเฉลี่ย เหมาะสำหรับการทำรายงานวิจัยในชั้นเรียน

### 3.7 ระบบตรวจจับและตรวจสอบการทุจริตในการสอบ (Exam Integrity Center - `/admin/exam-integrity`)
นวัตกรรมด้านความโปร่งใสในการวัดและประเมินผลออนไลน์:
1. เข้าเมนู **"การทุจริตระหว่างสอบ"**
2. ระบบตรวจจับพฤติกรรมเสี่ยง 5 ด้าน ได้แก่:
   - ⚠️ **สลับหน้าจอ (Tab Switch):** สลับไปเปิดค้นหาคำตอบในแท็บอื่น
   - ⚠️ **สลับออกนอกหน้าต่าง (Window Blur):** สลับไปเปิดโปรแกรมภายนอก เช่น Line, Discord, หรือ Notepad
   - ⚠️ **พยายามคัดลอก (Copy Attempt):** กดปุ่ม Ctrl+C เพื่อคัดลอกข้อสอบไปค้นหา
   - ⚠️ **คลิกขวา (Right Click):** พยายามเปิด Context Menu
   - ⚠️ **เปิดเครื่องมือนักพัฒนา (DevTools Open):** กด F12 เพื่อพยายามดูเฉลยใน Source Code
3. **แดชบอร์ดตรวจสอบ (Integrity Viewer):**
   - แสดงรายการบันทึก (Logs) พร้อมชื่อนักเรียน, วิชา, เวลาที่เกิดเหตุ (Timestamp), และประเภทการฝ่าฝืน
   - แสดงแท็กเตือนสีแดงสำหรับนักเรียนที่ทำผิดกฎเกินกำหนด (High-Risk Incident)
   - ไทม์ไลน์แสดงพฤติกรรมระหว่างการสอบอย่างละเอียด

### 3.8 ระบบจัดการและวิเคราะห์แบบประเมินความพึงพอใจ (Satisfaction Survey & Evaluation - `/admin/evaluation`)
รองรับกระบวนการวิจัยทางการศึกษาอย่างสมบูรณ์แบบ:
1. **เครื่องมือสร้างแบบสอบถาม (Form Builder):**
   - กำหนดชื่อแบบประเมินและคำชี้แจง
   - เพิ่ม/แก้ไข/ลบ ด้านการประเมิน (Dimensions) เช่น ด้านเนื้อหา, ด้านการใช้งาน, ด้าน AI ผู้ช่วยสอน
   - เพิ่มข้อคำถามรายข้อ (Items) ตามมาตรวัดลิเคิร์ท (Likert Scale 5 ระดับ)
2. **ปุ่มควบคุมการเปิด/ปิดรับข้อมูล (Toggle Open/Lock Survey):**
   - ครูสามารถคลิก "เปิดรับแบบประเมิน" เมื่อนักเรียนเรียนจบ หรือ "ปิดรับ" เมื่อครบกำหนดเวลา
3. **การประมวลผลเชิงสถิติอัตโนมัติ (Statistical Analytics):**
   - คำนวณจำนวนผู้ตอบทั้งหมด
   - คำนวณ **ค่าเฉลี่ย ($\bar{x}$)** และ **ส่วนเบี่ยงเบนมาตรฐาน (S.D.)**
   - แปลผลระดับความพึงพอใจ (มากที่สุด, มาก, ปานกลาง, น้อย, น้อยที่สุด) แยกตามรายด้านและรายข้อ
4. **การติดตามผู้ที่ยังไม่ได้ประเมิน (Pending Students Tracker):**
   - แสดงรายชื่อนักเรียนที่ยังไม่ได้ทำแบบประเมิน
   - ปุ่มคลิกเดียวเพื่อคัดลอกอีเมลหรือรายชื่อ สำหรับส่งแจ้งเตือน
5. **การส่งออกรายงานการวิจัย (Export Research Excel):**
   - ส่งออกผลการวิเคราะห์สถิติสรุปตารางวิจัยได้ทันที โดยไม่ต้องพิมพ์ข้อมูลคำนวณใหม่ใน SPSS หรือ Excel

### 3.9 การตรวจสอบประวัติการสนทนากับ AI (AI Chat Logs - `/admin/ai-logs`)

2. ครูผู้สอนสามารถอ่านประวัติการถาม-ตอบระหว่างนักเรียนกับ Gemini AI Tutor
3. **ประโยชน์เชิงการวิจัยและการสอน:**

   - สามารถนำข้อมูลคำถามที่พบบ่อยมาจัดกิจกรรมเสริมแรงหรือปรับปรุงสื่อการสอนในคาบถัดไป

### 3.11 การจัดการบัญชีผู้สอนและตั้งค่าระบบ (Teacher Management & Settings - `/admin/teachers` & `/admin/settings`)
- **จัดการครูผู้สอน (Multi-Teacher):** รองรับสถานศึกษาที่มีครูผู้สอนหลายท่านในรายวิชาเดียวกัน แยกบัญชีและโปรไฟล์อย่างอิสระ
- **ตั้งค่าสถาบัน (System Settings):** ปรับแต่งชื่อสถานศึกษา, โลโก้, โดเมนอีเมลของวิทยาลัย (@svc.ac.th), และระยะเวลาหมดอายุเซสชัน

## 4. คู่มือการใช้งานระบบ: ส่วนของนักเรียน (Student Portal)

### 4.1 การเข้าสู่ระบบของนักเรียน (Student Authentication)
1. ไปที่หน้าหลักของระบบ หรือคลิกเข้าสู่ระบบที่ `/login`
2. กดปุ่ม **"Sign in with Google"**
3. เลือกบัญชีอีเมลของสถานศึกษา หรือบัญชี Google ที่ลงทะเบียนไว้
4. เมื่อเข้าสู่ระบบสำเร็จ ระบบจะนำผู้เรียนเข้าสู่หน้า **แดชบอร์ดภาพรวมการเรียน** ทันที

---

### 4.2 แดชบอร์ดการเรียนรู้ส่วนบุคคล (Student Dashboard - `/student/dashboard`)
ศูนย์รวมข้อมูลความก้าวหน้าทางการเรียนของผู้เรียน:
- **แถบความก้าวหน้ารวม (Progress Bar):** แสดงร้อยละความสำเร็จของรายวิชา
- **สถิติสะสม (Real-time Stats):** แสดงเวลาเรียนสะสม (Study Hours), จำนวนหน่วยการเรียนที่สำเร็จ, คะแนนค่าประสบการณ์ (XP Points)
- **กราฟวิเคราะห์ผลการสอบ (Exam Evaluation Chart):** แผนภูมิแท่งเปรียบเทียบคะแนนที่ได้ในแต่ละหน่วยการเรียนรู้กับคะแนนเต็ม ช่วยให้ผู้เรียนประเมินจุดเด่นและจุดที่ต้องพัฒนาตนเองได้ทันที
- **การ์ดเข้าเรียนต่อทันที (Continue Learning):** ปุ่มกดลัดเพื่อเข้าสู่บทเรียนล่าสุดที่กำลังศึกษาอยู่

---

### 4.3 ห้องเรียนออนไลน์และสื่อการสอนมัลติมีเดีย (Classroom & Multimedia - `/student/learn/[id]`)
1. เข้าสู่หน้าห้องเรียนผ่านเมนู **"บทเรียนทั้งหมด"**
2. **แถบสารบัญบทเรียน (Curriculum Sidebar):**
   - แสดงโครงสร้างหน่วยการเรียนรู้และบทเรียนย่อยทั้งหมด
   - มีสัญลักษณ์แสดงสถานะ: 🔒 ล็อกอยู่, ⏳ กำลังเรียน, ✅ เรียนสำเร็จแล้ว
3. **เงื่อนไขการเรียนรู้ (Pre-test Prerequisite):**
   - ในหน่วยที่มีแบบทดสอบก่อนเรียน (Pre-test) ระบบจะล็อกเนื้อหาบทเรียนไว้ จนกว่าผู้เรียนจะทำแบบทดสอบก่อนเรียนเสร็จสิ้น เพื่อประโยชน์ในการเปรียบเทียบผลสัมฤทธิ์ทางการเรียนก่อนและหลังเรียน
4. **สื่อการเรียนรู้:**
   - หน้าต่างเล่นวิดีโอคมชัด สามารถหยุด บันทึกการรับชมได้
   - เอกสารประกอบการเรียนและโค้ดตัวอย่าง SQL ที่อ่านง่าย พร้อมโหมดกลางวัน/กลางคืน (Light/Dark Mode)

---

### 4.4 การทำแบบทดสอบและระบบป้องกันการทุจริต (Quizzes & Anti-Cheating Interface)
1. **การเริ่มทำแบบทดสอบ:**
   - ตรวจสอบคำชี้แจง, จำนวนข้อ, คะแนนเต็ม, และเวลาในการทำข้อสอบ
   - กดปุ่ม **"เริ่มทำแบบทดสอบ"**
2. **ระหว่างการทำแบบทดสอบ:**
   - ข้อสอบจะถูก **สุ่มลำดับคำถาม (Question Shuffling)** เพื่อป้องกันการลอกคำตอบ
   - มี **ตัวจับเวลานับถอยหลัง (Countdown Timer)** แสดงบนแถบหัวข้ออย่างชัดเจน
   - **ระบบเฝ้าระวังความซื่อสัตย์ (Anti-Cheating Monitoring):**
     - หากผู้เรียนสลับแท็บเบราว์เซอร์ ย่อหน้าต่าง หรือคลิกออกนอกหน้าจอ ระบบจะแสดงหน้าต่างแจ้งเตือนเตือนสติทันที พร้อมบันทึกพฤติกรรม
     - หากพบการพยายามฝ่าฝืนซ้ำ ระบบจะตัดสิทธิ์การทำข้อสอบ (Disqualified) โดยอัตโนมัติ
3. **การส่งข้อสอบและตรวจผล:**
   - กดปุ่ม **"ส่งคำตอบ"** หรือส่งอัตโนมัติเมื่อหมดเวลา
   - ระบบจะตรวจผลคะแนนทันที (Instant Auto-Grading)
   - ผู้เรียนสามารถกด **"ดูเฉลยและคำอธิบาย"** เพื่อศึกษาแนวคิดที่ถูกต้องในแต่ละข้อ

---

### 4.5 การส่งงานและการบ้านออนไลน์ (Assignment Submission)
1. ในบทเรียนที่มีการมอบหมายงาน ผู้เรียนจะเห็นคำอธิบายงานและเกณฑ์การให้คะแนน (Rubric)
2. ดาวน์โหลดใบงานหรือโจทย์ตัวอย่าง (ถ้ามี)
3. เมื่อทำงานเสร็จสิ้น:
   - แนบไฟล์ผลงาน เช่น ไฟล์ฐานข้อมูล `.accdb`, สคริปต์ `.sql`, รายงาน `.pdf` หรือรูปภาพ
   - พิมพ์ข้อความบันทึกแนบถึงคุณครู (Optional)
   - กดปุ่ม **"ส่งใบงาน"**
4. **การติดตามสถานะ:**
   - ระบบจะแสดงสถานะ **"รอตรวจ (Under Review)"**
   - เมื่อครูผู้สอนตรวจเสร็จ สถานะจะเปลี่ยนเป็น **"ตรวจแล้ว (Graded)"** พร้อมแสดงคะแนนที่ได้รับ และข้อเสนอแนะที่คุณครูเขียนให้

---

### 4.6 การใช้งานผู้ช่วยสอน AI ประจำตัว 24 ชั่วโมง (Gemini AI Tutor)
นวัตกรรมผู้ช่วยสอนอัจฉริยะที่อยู่คู่กับผู้เรียนตลอดทุกหน้าจอ:
1. **วิดเจ็ตแชทบอทมุมขวาล่าง (Floating Chatbot Widget):**
   - คลิกที่ไอคอนหุ่นยนต์ **DBASE AI Tutor** ที่มุมขวาล่างของหน้าจอ
2. **ความสามารถของ AI:**
   - อธิบายแนวคิดเรื่องฐานข้อมูล เช่น ความแตกต่างระหว่าง Primary Key และ Foreign Key
   - ช่วยตรวจสอบข้อผิดพลาด (Syntax Error) ของโค้ดคำสั่ง SQL
   - ช่วยอธิบายขั้นตอนการทำ Normalization พร้อมยกตัวอย่างตาราง
   - สร้างตัวอย่างโจทย์แบบฝึกหัดทบทวนความเข้าใจ
3. **เครื่องมืออำนวยความสะดวกในห้องแชท:**
   - แสดงผลโค้ด SQL อย่างเป็นระเบียบ พร้อมกล่องโค้ดสีสวยงาม
   - มีปุ่ม **"คัดลอกโค้ด (Copy Code)"** เพื่อนำไปทดลองรันในโปรแกรมจัดการฐานข้อมูลได้ทันที
   - ปุ่มล้างบทสนทนา (Reset Chat)
4. **ลิงก์ Gemini AI Custom Gem:** มีเมนูลัดเปิดใช้งาน Gemini AI ในเวอร์ชันเต็มบน Google Workspace

### 4.7 การตรวจสอบคะแนนและกราฟวิเคราะห์ผลการเรียน (Student Scores - `/student/scores`)
- ผู้เรียนสามารถตรวจสอบผลคะแนนเก็บ คะแนนสอบย่อย และคะแนนการส่งงานของตนเองได้แบบรวมศูนย์
- มีการแสดงผลเปรียบเทียบคะแนนสอบก่อนเรียน (Pre-test) และหลังเรียน (Post-test) เพื่อสะท้อนความก้าวหน้าทางวิชาการ

### 4.8 ระบบออกเกียรติบัตรอิเล็กทรอนิกส์อัตโนมัติ (E-Certificate - `/student/certificates`)
แรงจูงใจและการรับรองสมรรถนะดิจิทัล:
1. เข้าเมนู **"ใบรับรอง (Certificates)"**
2. **เงื่อนไขการได้รับเกียรติบัตร:**
   - ศึกษาบทเรียนครบถ้วนตามหลักสูตร (100% Completion)
   - สอบผ่านแบบทดสอบวัดผลสัมฤทธิ์หลังเรียน (Post-test) ตามเกณฑ์คะแนนที่กำหนด
   - ส่งใบงานครบทุกหน่วย
3. **การพิมพ์และดาวน์โหลด:**
   - เมื่อผ่านเกณฑ์ ระบบจะปลดล็อกเกียรติบัตรอัตโนมัติ
   - แสดงใบประกาศนียบัตรขนาดมาตรฐาน A4 แนวนอน ออกแบบอย่างประณีต
   - มีชื่อ-สกุลของผู้เรียน, รหัสและชื่อวิชา, วันที่สำเร็จการศึกษา, และลายเซ็นครูผู้สอน
   - รองรับการกดปุ่ม **"พิมพ์เกียรติบัตร (Print / PDF)"** ได้ทันที

---

### 4.9 กล่องข้อความติดต่อครูผู้สอน (Student Messages - `/student/messages`)
- ช่องทางติดต่อสื่อสารโดยตรงระหว่างนักเรียนกับครูผู้สอน
- สามารถพิมพ์ปรึกษาปัญหาการเรียน การส่งงาน หรือข้อติดขัดในเนื้อหา
- ได้รับการตอบกลับจากคุณครูพร้อมระบบแจ้งเตือน

---

### 4.10 การทำแบบประเมินความพึงพอใจต่อระบบ (Student Evaluation - `/student/evaluation`)
- เมื่อสิ้นสุดการเรียนรู้ ผู้เรียนจะเข้าทำแบบประเมินความพึงพอใจ 5 ระดับ

## 5. เกณฑ์และแบบประเมินคุณภาพระบบสำหรับผู้เชี่ยวชาญ (Expert Evaluation Rubrics)

แบบประเมินนี้จัดทำขึ้นตามหลักวิชาการวิจัยทางการศึกษาและมาตรฐานการประเมินคุณภาพสื่อนวัตกรรม เพื่อให้ผู้เชี่ยวชาญใช้บันทึกผลการประเมิน:

### เกณฑ์การให้คะแนน (5-Point Likert Scale)
| ระดับคะแนน | ความหมาย | ช่วงคะแนนเฉลี่ย |
| :---: | :--- | :---: |
| **5** | มีความเหมาะสม / คุณภาพอยู่ในระดับ **มากที่สุด** | 4.51 – 5.00 |
| **4** | มีความเหมาะสม / คุณภาพอยู่ในระดับ **มาก** | 3.51 – 4.50 |
| **3** | มีความเหมาะสม / คุณภาพอยู่ในระดับ **ปานกลาง** | 2.51 – 3.50 |
| **2** | มีความเหมาะสม / คุณภาพอยู่ในระดับ **น้อย** | 1.51 – 2.50 |
| **1** | มีความเหมาะสม / คุณภาพอยู่ในระดับ **น้อยที่สุด** | 1.00 – 1.50 |

| 1.1 | การทำงานของระบบในส่วนต่างๆ มีความถูกต้อง ครบถ้วน และไม่มีข้อผิดพลาด (Bug-Free) | | | | | |
| 1.2 | ความเร็วในการตอบสนอง การโหลดหน้าเว็บ และการประมวลผลข้อมูล (System Performance) | | | | | |
| 1.3 | การเชื่อมต่อฐานข้อมูล Supabase และการอัปเดตข้อมูลแบบ Real-time มีความเสถียร | | | | | |

| 2.1 | การออกแบบหน้าจอมีความสวยงาม ทันสมัย ดึงดูดความสนใจของผู้เรียน (Modern Aesthetics) | | | | | |
| 2.2 | เมนูและปุ่มควบคุมมีความชัดเจน จัดวางอย่างเป็นระบบ ง่ายต่อการใช้งาน (Intuitive Navigation) | | | | | |

| 2.4 | การรองรับโหมดกลางวันและกลางคืน (Light/Dark Mode Theme) ช่วยถนอมสายตาขณะเรียนรู้ | | | | | |

| 3.4 | ระบบบันทึกประวัติการคุย AI (AI Logs) ช่วยให้ผู้สอนสามารถติดตามการเรียนรู้ของผู้เรียนได้อย่างมีประสิทธิภาพ | | | | | |
